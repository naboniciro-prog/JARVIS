# Jarvis 2.0

Asistente personal por voz para Windows, en español rioplatense.

- Se activa con **"Hey Jarvis"** (detección local con openWakeWord) o con **doble aplauso** (umbral adaptativo al ruido).
- Reconocimiento de voz con Google, voz neural con Edge TTS, conversación con Claude.
- Comandos locales: hora, fecha, clima, abrir programas y páginas, música, volumen, recordatorios, memoria.

La guía completa de instalación y uso está en [LEEME.txt](LEEME.txt).

```bash
python -m pytest tests
```
